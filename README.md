# wordcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [wordcraft](https://github.com/storytold/wordcraft), a Word-style word processor by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/wordcraft/latest/`
- Specific version: `/wordcraft/v<version>/`
- Version list: `/wordcraft/versions.json`

Each version folder is the unmodified contents of upstream's `wordcraft-web-<version>.zip` release asset, including its license files. Upstream license: . A scheduled workflow mirrors new releases.
